# SerenVeyra 个人网站


## 项目介绍

这是我的个人网站项目。

我希望通过这个网站记录：

- AI 与人力资源（AI + HR）的探索
- 写作与思考
- 个人成长过程
- 项目实践与作品展示


这个网站不仅是一个个人主页，

也是一个长期维护的个人知识库。


---

## 网站定位


网站定位：

> 一个持续记录思考、学习和创造的个人空间。


主要关注方向：

- AI 与 HR 的结合
- 人与组织关系
- 技术时代下的个人成长
- 写作与内容创造
